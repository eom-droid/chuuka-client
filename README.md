# 주문제작케이크 플랫폼 ‘CHUUKA’

## 프로젝트 소개

- ‘CHUUKA’는 주문제작케이크 가게 정보를 위치기반으로 보여주는 플랫폼 입니다
- 이벤트와 관련된 컨텐츠도 확인할 수 있습니다.

배포: [https://chuuka.web.app](https://chuuka.web.app/)

## 팀원구성

개발: 엄태호

기획 및 디자인: 송준혁

## 1. 개발 환경


- Front-end: VueJS
- Back-end: Firebase Function, Database, Storage
- 기타: Google Analytics
- 서비스 배포환경: Firebase Hosting

## 2. 신경쓴 부분

### 위치 기반 주변 케이크 가게 전시

- naver map api 사용 위치기반 가게 전시
- 오픈여부 확인

### Serverless 서비스 구현

- Firebase 활용 서버리스 서비스 구현

## 3. 개선목표

- 위와 같은 B2C 서비스 우선 진행 이후 기존 주문제작케이크 가게와의 협업
- 가게 주문 받는 시스템 및 재고 관리 시스템 개발
